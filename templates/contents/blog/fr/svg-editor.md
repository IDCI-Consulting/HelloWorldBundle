
# Comment créer et utiliser un éditeur SVG ? #
![SVG logo](/images/blog/svg-logo.png "SVG logo")

## Introdution ##

### Qu'est-ce qu'un éditeur SVG ? ###

- (Graphique Vectoriel Adaptable)
- décrit un ensemble de graphiques vectoriels
- basé sur fabricJS
- vectoriel
- format .svg léger et agrandissable à l'infini sans perte de qualité
- spécifié par le W3C

### Quelle utilisation ? ###

- exemples: formes géométriques et cartographie
- Utilisation de plugins : dispo via une librairie
- Editeur = canevas vierge, ajout de plugins pour le compléter -> modifier éléments

## Créer un nouvel éditeur SVG ##
